
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a playable Hangman game in Python. You will practice string manipulation, loops, conditionals, user input, and random selection.

## 📝 Tasks

### 🛠️ Build the Game

#### Description

Create a program that randomly selects a word and allows the player to guess its letters before running out of attempts.

#### Requirements

Completed program should:

- Randomly select a word from a predefined list.
- Accept one-letter guesses from the player.
- Display the letters guessed correctly and use underscores for hidden letters, such as `_ _ _ _ _`.
- Track the number of incorrect guesses remaining.
- End when the player guesses the complete word or runs out of attempts.

### 🛠️ Handle Game Results

#### Description

Add clear feedback so the player understands the result of each guess and the final outcome of the game.

#### Requirements

Completed program should:

- Tell the player whether each guess is correct or incorrect.
- Prevent the same letter from being counted more than once.
- Display a win message when the player reveals the word.
- Display a lose message and reveal the word when the player runs out of attempts.
